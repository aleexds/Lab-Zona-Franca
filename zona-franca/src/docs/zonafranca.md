# ZoFranca CR - Plataforma de Gestión y Pre-clasificación con IA

Plataforma web para la automatización, pre-evaluación y seguimiento de solicitudes de instalación de empresas en el régimen de Zona Franca de Costa Rica, bajo lineamientos de **PROCOMER**.

---

## Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript ES6+ (Fetch API, Async/Await)
* **Backend Simulado:** `json-server` (REST API local)
* **Diseño / Prototipado:** Stitch IDE
* **Gestión del Proyecto:** Trello & GitHub (Branching Strategy)

---
